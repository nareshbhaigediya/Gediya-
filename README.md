# Gediya — Premium Android Chat Starter

A Kotlin + Jetpack Compose starter project with a premium black-and-gold interface.

## Open
1. Install Android Studio.
2. Choose **Open** and select this `Gediya` folder.
3. Allow Gradle sync to finish.
4. Run the `app` configuration on an Android emulator or USB-connected phone.

## Included
- Premium dark / gold chat-list screen
- Search conversations
- Demo conversation screen
- Local message sending (messages stay in app memory)

## Important
This is a UI starter, not a production messaging service. It does not yet include accounts, OTP, a server, real-time delivery, push notifications, encryption, media upload, or voice/video calls. Those require a backend and additional security work. Do not use it for sensitive conversations until those features are properly implemented.
